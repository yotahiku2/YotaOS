# YotaOS

YotaOS is a custom Linux distribution focused on:

- Performance and low system overhead
- Clean desktop experience
- Programming and cybersecurity
- Gaming and everyday desktop use
- Sensible defaults without unnecessary bloat

## Status

Version: 0.2-dev
Base: Fedora
Architecture: x86_64

## Project Structure

- branding/  - Logos, wallpapers, boot branding
- configs/   - System and desktop configuration
- packages/  - YotaOS package selections
- scripts/   - Setup and customization scripts
- build/     - ISO build configuration
